# CedroDB visual identity

The selected logo combines a C-shaped stack of storage layers with a sprout in emerald green.

Use `docs/assets/cedrodb-logo.png`, a transparent PNG, for project documentation and social material. Preserve its proportions and transparent margins; place it on a light background for clear contrast. This is the second design selected by the project author.

The artwork was generated with imagegen using the concept: geometric C built from data layers with an integrated sprout.
